🧰 /uses

Hardware, software, dan layanan yang kupakai sehari-hari. Terinspirasi dari uses.tech.

🖥️ Hardware

  • Home server "z6" — AMD Ryzen 9 9900X, GTX 1660 Super, 15 GB RAM. Jantung homelab: semua container, pipeline CCTV, agent AI, dan situs ini.
  • Mini-PC — Intel i3-1215U, node khusus analitik CCTV realtime (Frigate + face recognition).
  • STB Armbian — single-board kecil di mesh sebagai controller tambahan.
  • VPS kecil (Tencent Cloud) — 2 vCPU, satu-satunya pintu publik: reverse proxy, analytics, dan jalur masuk ke rumah.

🧩 Software

  • Ubuntu Linux di semua node.
  • Docker + Compose untuk semua layanan; Caddy sebagai reverse proxy dengan sertifikat otomatis.
  • Tailscale — mesh VPN; layanan privat tidak pernah terekspos langsung ke internet.
  • Cloudflare — DNS, edge, dan TLS untuk nama domain publik.
  • Python & FastAPI sehari-hari untuk ML dan backend; Go dan Node.js untuk proyek yang sedang tumbuh.
  • PostgreSQL / MySQL, Jekyll (situs ini), Umami (analytics tanpa cookie pihak ketiga).
  • Hermes Agent (Nous Research) — agent AI yang ikut mengurus infra ini, termasuk menulis halaman yang sedang kamu baca.

🏠 Layanan homelab

  • Frigate + ArcFace — deteksi orang & face recognition dari CCTV, alert WhatsApp realtime.
  • Jellyfin — media server.
  • Paperless-ngx — arsip dokumen.
  • Vaultwarden — password manager self-hosted.
  • Uptime Kuma — monitoring & alert.
  • Honcho — memori jangka panjang untuk agent AI-ku.
  • Umami — analytics situs ini.

Daftar ini hidup. Terakhir diperbarui: September 2026 (kamu bisa lihat status live-nya di /lab).
