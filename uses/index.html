🧰 /uses

Hardware, software, and services I use daily. Inspired by uses.tech.

🖥️ Hardware

  • z6 — mini-PC (Intel i3-1215U, 16 GB RAM): the 24/7 node at home. All the containers, real-time CCTV analytics (Frigate + face recognition), the AI agents, and this website.
  • sumopod — small VPS (Tencent Cloud, 2 vCPU / 4 GB RAM): the only public entry point — reverse proxy + Cloudflare, monitoring, analytics, LLM router.
  • armbian — STB (Armbian Linux): Pi-hole for network-wide DNS + a power controller that wakes the workstation.
  • workstation — Ryzen 9 9900X (32 GB RAM, GTX 1660 Super): runs Omarchy (Arch-based), my on-demand compute for heavy workloads. Usually off, powered on when needed.
  • MacBook Neo (macOS) — my daily driver when I'm mobile.

🧩 Software

  • Terminal-first, all day: Ghostty as the terminal, LazyVim (Neovim) as the IDE, and herdr as the terminal workspace manager that runs my AI coding agents and dev sessions. I basically live in the terminal.
  • Linux everywhere: Ubuntu on z6, OpenCloudOS on the VPS, Armbian on the STB, Omarchy (Arch-based) on the workstation.
  • Docker + Compose for all services; Caddy as reverse proxy with automatic certificates.
  • Tailscale — mesh VPN; private services are never exposed directly to the internet.
  • Cloudflare — DNS, edge, and TLS for public domain names.
  • Python & FastAPI daily for ML and backend; Go and Node.js for projects that are growing.
  • PostgreSQL / MySQL, Jekyll (this site), Umami (analytics without third-party cookies).
  • OmniRoute — self-hosted multi-provider LLM gateway; routes requests across models for my agents and side projects.
  • Hermes Agent (Nous Research) — the AI agent that helps run this infrastructure, including writing the page you are reading.

🏠 Homelab services

  • Frigate + ArcFace — person detection & face recognition from CCTV, with real-time WhatsApp alerts.
  • Jellyfin — media server.
  • Paperless-ngx — document archive.
  • Vaultwarden — self-hosted password manager.
  • Actual Budget — local-first envelope budgeting, self-hosted sync server.
  • Uptime Kuma — monitoring & alerts.
  • Beszel — per-node resource metrics (CPU, RAM, disk, uptime).
  • Dozzle — live container logs.
  • Honcho — long-term memory for my AI agents.
  • Umami — analytics for this site.
  • Excalidraw — whiteboard & diagrams.
  • dbgate — database GUI; IT-Tools — dev utilities.
